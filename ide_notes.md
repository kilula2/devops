# Заметки: VS Code vs Терминал

**Что удобнее в VS Code:**
1. Панель Source Control показывает, в какой ветке я нахожусь, прямо в статус-баре.
2. Визуально удобно сравнивать файлы (diff) — сразу видно, что удалили, а что добавили.
3. Кнопка "Commit" сразу отправляет изменения (если настроено), экономит время.

**Что удобнее в терминале:**
1. Массовые операции (например, переименовать файл и сразу сделать коммит) — в CLI быстрее, чем через интерфейс.
