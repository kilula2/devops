# Конфигурация виртуальной машины devops-vm

## 1. Параметры машины
*   ОЗУ: 2048 МБ
*   Ядра: 2
*   Диск: 25 ГБ (динамический)

## 2. Сетевые интерфейсы
*   Адаптер 1 (NAT): IP 10.0.2.15 (доступ в интернет)
*   Адаптер 2 (Host-only): IP 192.168.101.4 (доступ с хоста, для Nginx)

## 3. Правило проброса портов
*   Порт хоста 2222 -> Порт гостя 2222 (SSH)

## 4. Учётные записи
*   kilula2: основной пользователь (sudo)
*   devops: пользователь для удаленного доступа (sudo, вход по SSH-ключу)

## 5. Служба SSH
*   Порт: 2222
*   Расположение конфига: /etc/ssh/sshd_config.d/99-hardening.conf
*   Измененные директивы: PermitRootLogin no, PasswordAuthentication no, MaxAuthTries 3, AllowUsers devops

## 6. Правила межсетевого экрана
*   Default incoming: deny
*   Default outgoing: allow
*   Разрешены порты: 2222/tcp (limit), 80/tcp, 443/tcp

## 7. Снимки состояния
*   01-clean-install (базовая установка)
*   02-keys-configured (после настройки SSH-ключей)
*   03-ssh-hardened (после настройки SSH и UFW)
*   04-nginx-https (после настройки HTTPS в ПР6)
*   05-docker-compose (после запуска контейнеров в ПР7)

## 8. Веб-сервер Nginx (ПР6)
*   Конфигурация сайта: /etc/nginx/sites-available/devops-site
*   Корневая папка статики: /var/www/devops-site
*   SSL сертификат: /etc/ssl/certs/devops.crt
*   SSL ключ: /etc/ssl/private/devops.key (права 600, владелец root)

## 9. Контейнеризация (ПР7)
*   Docker Engine установлен из официального репозитория.
*   Учетная запись `devops` включена в группу `docker`.
*   Проект расположен на сервере в каталоге `~/devops/app`.
*   Файл `.env` расположен по пути `~/devops/app/.env`, права доступа `600`.
*   Публикуемые порты: `127.0.0.1:5000` (приложение). Порт СУБД 5432 не публикуется.
*   Именованные тома: `app_db_data` (для PostgreSQL).
*   Обратный прокси-сервер Nginx настроен на передачу запросов с `/app/` на `http://127.0.0.1:5000/`.
