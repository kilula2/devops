# Сравнение Git и SVN

**1. Почему в Git ветвление "дешёвое", а в SVN - "дорогое"?**
Потому что в Git ветка - это просто указатель (ярлык) на определенный коммит. Создать ее можно за долю секунды, места на диске она почти не занимает. 
В SVN ветка - это физическое копирование всех файлов проекта в новую папку на сервере. Это занимает время и дисковое пространство, поэтому там ветвление считается "дорогим".

**2. Можно ли в SVN сделать коммит без интернета? Почему?**
Нет, нельзя. SVN - это централизованная система. В ней нет полной копии всей истории проекта на компьютере у разработчика. Чтобы сохранить изменения (сделать коммит), нужно обязательно отправить их на центральный сервер, а для этого нужен интернет.

**3. В каких сценариях SVN до сих пор может быть предпочтительнее Git?**
- В крупных корпорациях (банки, госсектор), где годами писалась старая система (legacy) и переводить весь проект на Git экономически невыгодно.
- Если нужно хранить огромные бинарные файлы (хотя сейчас для этого в Git есть Git LFS).
- Если компании нужен жесткий контроль доступа к отдельным папкам проекта (в SVN это настраивается проще на уровне файловой системы).
